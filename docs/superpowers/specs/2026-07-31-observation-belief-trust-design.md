# 觀測式信任層設計（Observation-sourced belief layer）

2026-07-31。取代現行 Gate 2 的單發殘差判決。
**修訂 2**（同日）：四份平行審計 + 三輪對抗式驗證後的重寫。變更理由見 §10。

## 1. 問題

Gate 2 比對「同儕廣播的宣稱」與「同儕自己發的 odom」——**兩條都是被測者自陳**。
同時偽造兩條的攻擊者殘差恆 0，偵測永遠不觸發（Pasqualetti et al. 2013：內容型偵測器
看不見與所有自陳一致的攻擊）。已實測：`LIE=0.30` 全程合作、殘差穩定 0.424 < 門檻，
零 block、零 evict，真實車身間隙被吃到 0.038 m。

判決層另有兩個已實測的失效：LOGONLY 對照臂的 split-brain（兩隻倖存者判決差 9.5 s、
keep-out 圈差 4.5 m）、凍結攻擊者的過期 roster 仍在投票造成 coordinator 死鎖。

## 2. 安全預算的正確變數（修訂 2 的核心，推翻先前版本）

避障是 HOCBF，最內層的屏障函數是 `h = |p_i − p_j|² − D_MIN²`，即**距離 ≥ 1.3 m**；
外面兩層 class-K 條件（`admm_constants.hpp:42-44`，離散二階 HOCBF）把它變成沿預測軌跡
每三個相鄰時刻一組的可執行約束。

關鍵事實：**`p_j` 全部來自同儕的廣播宣稱。** 所以約束保障的是「宣稱位置」的間距，
真實間距 = `D_MIN − e`，其中 `e` = 宣稱與真值的位移差。**接觸發生在 `e ≥ 0.433` 時**
（1.3 − 0.867）。

**目前常數下的涵蓋範圍（修訂 2.1，經獨立重推）**：`0.15 + 0.9·v_div ≤ 0.433` → **v_div ≤ 0.31 m/s**。
這只適用於**看不到對方時**——有觀測時 §4.1 的保守錨定讓謊言當場失效，與偵測延遲無關。

→ **吃掉安全裕度的是謊言位移，不是任何人的行走速度。**
決定性證據來自本專案自己的量測：一個**完全靜止**的 0.30 謊言（位移 0.424 m）
把車身間隙吃到 0.038 m，全程沒有任何接近速度。速度模型解釋不了，位移可以。

先前版本用「攻擊者速度 × 偵測時間」估裕度，那是沿用上一個研究問題的變數，錯的。

## 3. 目標與非目標

**目標**：讓物理安全不再依賴「宣稱誠實」。

**非目標**：真感知（本 spec 用零保真替身，見 §7）；Zikratov 的 reputation 陣列 S
（防串謀，N=3 無串謀情境可驗，留待 N≥5）；改動 ADMM 迭代、`admm_core/` 的任何數學
（含 `rti.cpp` 的 HOCBF 係數、`edge_h`、梯度、D_MIN）、Laplacian 編隊耦合、下層控制。

註：§5.3 的「證據來源加權」不在排除之列——它是同一條更新規則的一部分。被排除的是
S 那層跨代理一致性計分。

**設計紀律**（使用者要求，優先於一切便利）：泛用規則，不得有情境特化的 fallback。
每個離散行為都必須是同一條規則的讀數。參數必須有物理意義與量測/推導程序。

## 4. 三層，各自解決不同的事

修訂 2 把原本混為一談的「偵測」與「安全」拆開。這是本設計最重要的結構決定。

| 層 | 做什麼 | 依賴偵測延遲嗎 |
|---|---|---|
| **保守錨定**（§4.1） | 避障約束改用真身位置，謊言當場失效 | **否** |
| **信念累積**（§5） | 判定誰不可信，停止與它協作 | 是（8 拍） |
| **成員資格**（§6） | 走現行 `members[]` 多數決驅逐 | 是 |

先前版本讓物理安全等待偵測完成，於是偵測延遲直接吃安全裕度。拆開後，
**偵測延遲只影響「何時停止協作」，不再影響「會不會撞上」**。

### 4.1 保守錨定（新增，使用者 2026-07-31 核可）

在同儕狀態進入約束建構之前（`agent_core.cpp` 組裝 `xnow`/`xibar` 之處，
**不在 `admm_core/`**），對每個同儕 j：

```
δ_j = 觀測位置 − 宣稱 xnow          （無觀測 → δ_j = 0）
若 |觀測 − 自己| < |宣稱 − 自己|：把 δ_j 加到 j 的 xnow 與 每一個 xibar knot
否則：δ_j = 0
```

**為什麼平移整條而不是只換 xnow**：HOCBF 是相鄰三個 `h` 的差分組合。只換第 0 點會讓
差分看到一個不存在的跳躍，等於憑空要求巨大加速度（實測：0.5 m 的不一致需要約 21 m/s²
才救得回來，超出 QP box）→ QP 解不動。整條平移保持點與點的相對關係不變，
HOCBF 看到的動力學完全一樣，只是這串點被搬到真身所在處。

**為什麼取「較近者」**：說謊者**沒辦法讓自己看起來比實際更遠**。報偏就被觀測拉回；
反過來謊報「我很近」（造幽靈）則沿用宣稱，多讓一點空間，安全方向。

**數學零改動**：`edge_h`、`three_point`、γ₁γ₂、`CBF_CONSTR_COEF`、梯度、D_MIN、
ADMM 迭代全部不動 → 44 個 oracle 測試繼續有效。改的只是餵進去的座標。

**三個必須處理的實作風險**（都不是數學）：
1. **突然看見**：遮擋結束時 δ 可能階躍 → 約束瞬間收緊 → 可能無解。
   δ 需限制變化率（每拍上限 = MAX_VX·TS），且套用 δ 的那條約束比照屍體約束軟化。
2. **噪聲抖動**：δ 帶觀測噪聲 → 約束顫動。加死區：`|δ| < 3σ` 視為 0。
3. **G1 parity**：parity 測試用回環傳輸、無觀測通道 → δ ≡ 0 → 應仍逐位元相同。
   **實作前必須先驗證這點**，破了就是回退條件。

## 5. 信念層

### 5.1 證據

- **觀測來源**：`peer_truth_`。模擬期由 Gazebo plugin 的 `/robotN/hardware/odom` 餵入。
- **發布者鎖定（取代先前的空頭承諾）**：remap **不提供任何安全性**——它只是訂閱端的
  名稱替換，解析後仍是同一個全域 topic，任何行程都能寫。先前版本寫「remap 後同儕
  沒有發布者」是錯的，已刪除。真正的機制是
  `rclcpp::MessageInfo::get_rmw_message_info().publisher_gid`：DDS 寫者的 GUID
  隨每筆訊息送達、發送端偽造不了。**鎖定每個觀測 topic 上第一個看到的 GID，
  其餘寫者一律丟棄**（約 5 行，與傳輸層既有的冒充檢查同構且更強）。
  仍須跑一組「攻擊者同時偽造觀測通道」的對照臂，量出防禦退化幅度。

  **GID 鎖定的真正保證範圍（TOFU，必須寫進論文威脅模型）**：它鎖的是「第一個出現的寫者」，
  所以保證是「**通道建立之後才出現的寫者會被拒**」，不是「任何冒充者都會被拒」。兩個後果：
  1. **攻擊者搶先發布就贏**——鎖會鎖在攻擊者身上，反而把真正的 Gazebo 發布者當冒充者丟掉。
     這正是 Task 10 的「偽造觀測通道」對照臂該打的情境，不能只當理論風險。
  2. **合法發布者重啟會換 GUID**，於是它的樣本從此被當第二個寫者丟掉，該同儕的觀測通道
     **在該趟剩餘時間內靜默失效**——目前只有一則節流的警告，不會進到腳本的判定邏輯。
     這是無害重啟與攻擊在運維上無法區分的情形，**必須讓它浮到 run 的判定層**，否則會變成
     「防禦看起來在、其實沒在」的那一類故障（本專案已經吃過這種虧）。

  另有一個尚未端到端驗證的環節：remap 只在 launch 的 Python 層檢查過，還沒有在真的 ROS graph 上
  用 `ros2 topic info` 確認 `observed/robotJ` 真的解析到 `/robotJ/hardware/odom`。
  **第一次餵進實驗臂之前必須做這個煙霧測試。**
- **殘差的定義＝innovation**：`r = h(宣稱) − 實際量測`。模擬替身的 `h` = identity
  故退化成減法；真機的 `h` 需形狀模型或純距離比較（見 §7）。
- **必須同時查「計畫」**（使用者 2026-07-31 核可）：`xnow` 與 `xibar` 之間**沒有一致性
  檢查**——`agent_core.hpp:148-157` 自述「這個檢查曾經在這裡，後來不得不拿掉」，
  而 `agent_core.hpp:54-57` 與 `admm_agent_node.cpp:793` 兩處註解仍宣稱它存在（**須更正**）。
  後果：攻擊者可對「現在在哪」完全誠實、只在計畫裡漂移（每 knot 上限 0.165 m），
  把有效標準距從 1.300 m 侵蝕到 **0.354 m**（過膝蓋接觸線 1.22 m）。
  修法是殘差多一項：把同儕 k 拍前廣播、對應**本拍**的那個 knot，與同一個觀測比對，
  容差取追蹤誤差。復活 Gate 1 的鏈結檢查不可行——HOLD 本來就會產生 1.3 m 的落差。
- **可見性**：純函式 `admm::visible(p_i, p_j, obstacles, range)`，距離閘＋線段-圓遮擋。
  不可見 → **不產生證據**。遮擋用 CBF 半徑 0.30（實體樁 0.20）→ 略為過度遮擋，偏向棄權。
- **HOLD 不產生證據**（新增）：barrier 未解出的 slot 一律不更新信念。
  `peer_xnow_` 只在解出路徑賦值（`agent_core.cpp:129`），而 `last_seen_` 對每則
  接受的訊息都前進（`dds_transport.hpp:407`），所以現行的新鮮度守衛擋不住
  「凍結的宣稱 vs 移動的觀測」——實測上限為 2 拍 × 同儕速度 = 0.08–0.11 m 的假殘差，
  對 0.15 m 的判定邊界佔 55–73%。「沒有新鮮宣稱」與「看不到你」是同一條規則：無證據。
- **時間對齊**：觀測內插到**宣稱所屬的 slot**（`last_seen[j]·TS`），非當前 slot。
- **噪聲**：`hash(cycle_id, 觀測者, 被觀測者, noise_seed)` 的決定性函數。
  **`noise_seed` 必須逐 run 變動**——否則同一臂的每趟共用同一份噪聲實現，
  誤判率的量測實際上 n=1。
- **識別關聯（真感知才觸發）**：**絕不可用「離宣稱最近」做關聯**，那會讓攻擊者的謊言
  牽著關聯走、殘差被構造性壓到 0。必須用時間軌跡連續性。

### 5.2 訊息欄位

`AgentState.msg` 追加：

```
int32[]   ev_peer      # 這一拍我觀測到的同儕 id
float64[] ev_pos       # 對應觀測位置 (x,y)，長度 = 2 * len(ev_peer)
uint64    ev_slot      # 這批觀測所屬的 slot
```

廣播**位置**而非純量殘差：殘差不可否證，位置受幾何約束，接收者能在看不到目標時查核
(a) 是否在報告者感測範圍內 (b) 視線是否被柱子擋住 (c) 是否與其他觀測吻合。

**必須驗長度與內容**：`ev_pos.size() == 2*ev_peer.size()`、
**`ev_peer.size() ≤ roster 大小`、id 必須在 roster 內且不重複**。
否則一則百萬筆的訊息會在服務 barrier 的執行緒上反序列化（同主機還跑著 250 Hz WBC）。

**證據必須與它描述的 slot 同拍上線**：`send_state` 在 `AgentCore::step` 開頭呼叫
（`agent_core.cpp:93-100`），而信念層在 `step()` 回來之後才產生證據 → 不處理的話
slot k 廣播的是 slot k−1 的觀測，接收端拿去對 slot k 的宣稱，每筆轉述帶 0.055 m 系統偏差。
`ev_slot` 欄位使接收端能正確配對。

### 5.3 信念更新

對每個同儕 j 維護對數勝算 L_j（初值 0）。每 slot：

```
L_j ← λ · L_j + ℓ_self + clamp(Σ_i w_i · ℓ_i , ±l_max)
b_j = 1 / (1 + e^{−L_j})
```

- `ℓ(r) = −d_lie(2r − d_lie)/(2σ²)`，上下截斷 ±clamp_step。零交叉在 `r = d_lie/2`。
- **credit 與 penalty 不對稱**：正向（誠實）貢獻另外限制在 `clamp_step/4`。
  否則對稱的 ±clamp_step 讓**間歇說謊**永遠不會被定罪——交替說謊/誠實的不動點約 +1.0，
  攻擊者可以半數 slot 任意大幅說謊而永遠碰不到門檻。實驗矩陣須加一組間歇臂。
- `w_i` = 對來源 i 的信念（上一拍）。不受信任的來源 `w → 0`，自然無權重。
- **轉述總和上限 `l_max`（非每來源）**：先前版本每來源各自設限，N≥4 時三個轉述者
  相加即可越過門檻，違反「轉述證據單獨永不驅逐」。改為對**總和**設限後，
  該性質對任意 N 成立。
- **同來源同目標的重複報告飽和**，不累加。
- **λ 只對未封鎖的同儕生效**（見 §6）。
- **λ 只作用在信任側**（使用者 2026-08-01 核可）：`L > 0` 照常衰減、`L < 0` **不衰減**。
  兩者在物理上本來就不對稱——**現在誠實的狗下一秒可能被入侵，所以信任必須持續重新賺取；
  已經被入侵的狗不會自己變回誠實，所以懷疑不該隨時間自動消失。**
  修訂前對兩側一律衰減，等於**躲起來就能洗白**：累積到 −6 的同儕只要躲三秒（梅花樁場的
  尋常遮擋長度）就剩約 −1.3，抹掉八成不利證據。spec 原本寫「不可見→不產生證據」，
  但**衰減本身就是往清白方向的移動**，兩者不同——是我的措辭沒把差別寫清楚，實作照著寫。
- **下限 `l_evict − clamp_step`，非選配**：沒有負側衰減時，持續不利證據會讓 L 無界發散
  （log-only 的對照臂沒有封鎖來凍結它）。這是信任天花板的鏡像——**再多的過往誠實不該讓人免疫，
  再多的過往說謊也不該讓平反不可能**：從下限靠正面證據回到中性約 22 拍（約 2.2 秒）。
  代價：對誠實狗的**誤會也不會自己消失**，要靠「被看到正常」賺回（3 分的誤會約 0.6 秒）。
  可接受，因為誠實狗大多時間在視線內，且轉述指控仍會衰減、指控者被封鎖時直接清除。
  ⚠️ **持續性偏差不管有沒有衰減都會誤判**（衰減擋不住累積），故本改動只影響「短暫抽風」，
  與 §7 記載的真機偏差問題無關。

### 5.4 門檻的老實說法（取代先前的 α/β 推導）

先前版本宣稱門檻由目標誤判率 α=1e-4、漏檢率 β=0.01 經 Wald/SPRT 推導。
**在模擬條件下那個推導是空的**：σ ≈ 0.006–0.02 而 d_lie = 0.30，
`ℓ` 只在 `|r − 0.15| < 0.0027` 這條 **5 mm 寬**的帶內有梯度，比乾淨飛行殘差本身還窄。
每一筆真實樣本都飽和在 ±clamp_step，累積器實際上是**計數器**；
連續六筆的機率約 1e−73，不是 1e−4。Wald 恆等式需要未截斷的 `ℓ`，兩者不可兼得。

**老實的表述**：這是一個 `N = |l_evict| / clamp_step` 拍的**去抖動**規則，
N 由「總偵測時間必須塞進安全裕度」決定（§8）。截斷保留——它正是阻止單一離群值定罪的機制。
**SPRT 結構不是白做的**：真感知噪聲（§7 的 0.07–0.21 m）會讓那條帶展開到有意義的寬度，
屆時漸進式證據才真正發揮作用。這是本設計往真機遷移時的自然演化，須寫入論文。

## 6. 行為映射

| 行為 | 映射 |
|---|---|
| 保守錨定 | §4.1，**不等信念**，有觀測就生效 |
| admission | b 低於門檻 → 該同儕宣稱不被 commit（現行 `block_peer`），ADMM 更新式不動 |
| keep-out | 半徑 = f(b)，**f 在信任區間必須平坦且等於現行 pairwise 約束**；跌破門檻才套屍體圈。不信任側目前是階梯（＝現行 `corpse_keepout`），斜坡需量測支撐 |
| 成員資格 | b 跌破 `l_evict` → 現行 `members[]` 多數決驅逐 |

**keep-out 的平段是硬需求**：b 初值 0.5，若半徑在信任區間就膨脹，三狗以 1.40 m 隊形
spawn 的當下就違反約束——已記錄的「硬約束遇已違反狀態＝永久自鎖」。

**驅逐是永久的（修訂 2 更正）**：`block_peer` 只寫入 `blocked_`，
**`dds_transport.hpp` 全檔沒有任何解除路徑**。先前版本寫的 `l_rejoin` 遲滯
是我未查證就寫下的空話。**已刪除**。歸隊機制列為後續討論項，不在本 spec。
因此 λ 只對未封鎖的同儕生效——讓被定罪者的信念自然漂回中性，
會造成「信念說可信、傳輸層仍拒收」的不一致，比不衰減更糟。

**驅逐延遲**：`evict_after_lying_` 由 3 拍改為 **1 拍**（使用者核可）。
那 3 拍的耐心是為了不把網路抖動誤判成死亡而設；信念層已累積 8 拍證據，
該工作已經做過。節點自己的註解也主張「被抓到說謊的不該享有 hiccup 的耐心」。

**投票必須忽略已被排除者的票**：`majority_excluded`（`fleet_config.hpp:130-138`）
目前只跳過自己與空 roster，所以一個被凍結的攻擊者仍以完整一票參與，
一次相互誤判即可造成「無活狗」死鎖——本專案已實測過這個死局。
改為一次定點迭代：先算出被多數排除的集合，再把那些機器人的票剔除後重算。
**acceptance 4（stale-vote 死鎖消解）由這條負責，不是由 λ 負責**——先前版本歸錯機制。

## 7. 保真度階梯與誤差預算

模擬觀測通道是**零保真替身**：世界座標 ground truth + 噪聲 + range/遮擋。
真光達的鏈是 `點雲(lidar frame) → base_link(外參) → odom(姿態+漂移) → 共同世界座標`。

**判定邊界是 `d_lie/2 = 0.15 m`，不是 0.30**（修訂 2 更正：先前版本拿 0.30 比，樂觀 2 倍）。

| 來源 | 量級 | 對 0.15 m 邊界 |
|---|---|---|
| 姿態槓桿臂 | 1° → 0.070 m；3° → 0.21 m | 單項即可能越界 |
| 狗間里程漂移 | 路徑 1–5%，18 m → 0.2–1.0 m | 遠超，且隨時間成長 |
| 表面 vs 原點 | 最大約 0.4 m | 遠超；靠 innovation 形式消掉，不得併入 σ |
| 掃描去畸變 | ≈ 5 cm | 疊加 |

**共模警告**：第一手與轉述殘差共用同一個宣稱項，所以系統偏差是**共模**——
N 個目擊者是把偏差乘 N，不是平均掉。佐證只對噪聲有效，對偏差無效。

**真機結論**：證據應改用相對量（距離為主），可消掉座標系旋轉不匹配並削弱姿態槓桿臂；
但消不掉兩狗世界座標的平移不匹配，那需要相對定位骨幹。
**模擬量到的 σ 是下界**。真機上限制條件會**翻轉**：不是偵測太慢，而是誤判太多。

## 8. 參數與推導程序

| 參數 | 來源 |
|---|---|
| σ | 量測（乾淨飛行校準 run）。**必須驗證 `max r ≪ d_lie/2`**，否則誤判 |
| λ | 由「攻陷後行為改變的時間尺度」推導 |
| clamp_step、l_evict | 由**去抖動深度**定：`N = |l_evict|/clamp_step` 拍，且下式須塞進 0.433 m：<br>`d_lie/2 + (N + 1)·TS·v_div ≤ 0.433`<br>**`d_lie/2` 那一項不可省**（修訂 2.1 更正）：謊言位移要先長到判定邊界才開始產生不利證據，在那之前 llr 是正的、`L` 反而被推向天花板。省掉它會把涵蓋範圍從 0.31 m/s 誇大成 0.481 m/s |
| l_max | 信任天花板兼轉述總和上限，必須 `< |l_evict|` |

## 9. 實驗矩陣（3 狗，plum arena）

| 臂 | 設定 |
|---|---|
| A0 無防禦 | 偵測關 |
| A1 自陳 gate | 現行單發 EMA 偵測器（`obs_gate2=0`） |
| A2 觀測信念層 | 本 spec |
| A2-smear | 攻擊者不動自己位置，偽造對誠實同儕的觀測 |
| A2-duty | 間歇說謊（半數 slot） |
| A2-forged-obs | 攻擊者同時偽造觀測通道（量防禦退化） |

**協定紀律（審計發現，全部為必要條件）**：

1. **A1 的機制必須在整個矩陣期間仍然存在**。原計畫在信念層上線時刪除單發路徑，
   而信念層不讀 `obs_gate2` → A1 會變成 A2，acceptance 1 無法失敗。單發路徑保留到
   矩陣跑完。每個 agent 啟動時印一行「本次實際編譯並武裝的偵測器」，結果文件逐趟引用。
2. **兩條偽造通道必須同時開啟**。`ODOM_FAKE` 是啟動參數（t=0 生效）而 `LIE` 是觸發時
   才設 → 中間 A1 會用「誠實宣稱 vs 偽造 odom」算出 0.424 m 殘差、在攻擊開始前
   數分鐘就驅逐攻擊者。`inject_odom_fake` 改為可執行期設定，與 `inject_fake_offset`
   同一批送出；並斷言觸發前零次偵測告警。
3. **A0 必須跑得完**。腳本目前在 `min_pair < 0.90` 與「驅逐次數 < 2」時中止，
   而那正是無防禦臂必然發生的事 → 只有有防禦的臂能產出數字。A0 設 `LIE_LOGONLY=1`
   （倖存者之間的硬守衛保留），驅逐斷言改為依臂而定。回報**到達距離**而非布林值。
4. **smear 臂必須真的射得出來且可能失敗**：定義 env→param 對應、在 `LIE` 分支外送出、
   斷言 smear 目標被驅逐次數為 0、要求 smear 者的封鎖理由是信念判決，
   並加一組**正對照**（關閉轉述加權）證明誠實狗**本來會**被移除。
5. **量測不得取自 1 Hz 節流日誌**。節流狀態是 per call site 非 per peer，同儕交替
   → 20 拍丟 19 拍，而 σ 正是從那些行推導的。改為**逐 (slot, 觀測者, 目標) 寫一列
   未節流 CSV**：`r`、`L_self`、`L_total`、棄權理由碼。time-to-evict 以 sim time 定義，
   從攻擊者第一次偽造廣播的 slot 到各倖存者的 `block_peer`，逐倖存者回報。
6. **遮擋結果不得是「日誌沒有出現」**。節流、新鮮度守衛、空佇列、插值失敗、已封鎖、
   訂閱死亡都會產生同樣的沉默。改為**正面記錄棄權與理由碼**，要求 L 在窗內數值不變、
   窗後恢復，腳本化攻擊者路徑，並確認兩個觀測者對它都 `visible()==false`。
7. **排除規則預先登記**，只排除基礎設施故障；**每一趟嘗試都要進表**（含中止原因）。
   n=3 只做描述性報告，不宣稱統計顯著。
8. **量 `v_div`**（宣稱與真值的發散速度）——§2 說明它才是決定成敗的變數。

**驗收**（每條都必須可能失敗）：

1. A2 抓到 A1 結構上抓不到的雙通道偽造攻擊者；報出 time-to-evict 與 `v_div`。
2. **保守錨定使真實車身間隙不因謊言縮小**（§4.1 的直接檢驗，與偵測延遲無關）。
3. NO_KILL soak 零誤殺（噪聲＋不可見情境，且 `noise_seed` 逐趟不同）。
4. 遮擋：棄權有正面記錄、L 不變、現身後恢復並偵測到。
5. smear 臂：誠實狗零驅逐，smear 者被抓；正對照顯示關閉加權時誠實狗會被移除。
6. 間歇臂：非對稱 credit 使間歇說謊者仍被定罪。
7. stale-vote 死鎖場景：定點投票修正後不再死鎖。
8. 回歸：44 oracle + ctest 全過；`b≡1` 且 `δ≡0` 時與現行系統 bit-identical（G1 parity）。

## 10. 已知盲區（誠實條款）

- **對稱 1v1**：證據對稱、第三方失明 → 不開除，互相 keep-out。BFT 需 3f+1，
  理論不可判定。N=3 時**每一次接近本來就都是這個情形**（只有兩個可能的觀測者），
  所以這個盲區比先前版本承認的更大。
- **轉述證據單獨永不驅逐**：由總和上限保證，對任意 N 成立。
- **量測不到的方向**：innovation 只在感測器量得到的方向非零。純距離證據下，
  沿等距圓切向的偏移恆為 0。解法：保留方位，或用兩個位置不同的觀測者。
- **偵測的是不一致，不是意圖**：估測器壞掉的誠實狗與說謊者無法區分。
  這是特性（一套機制涵蓋故障與攻擊），論文措辭須用「不可信」而非「惡意」。
- **同權限攻擊**：被入侵的行程可呼叫其他 agent 的參數服務
  （`detection_log_only:=true` 直接解除武裝）、可發布 latched `/formation/plan` 與
  `/robotN/goal`。本設計不防這些，威脅模型必須明說。
- **`EdgeXi`/`EdgeZ` 未經 Gate 1**：`gateCheck` 只跑 AgentState，這兩者直接 commit。
  比本設計處理的洞更廉價，列為已知缺口。
- **沉默規避**：攻擊者可永不報告觀測，與「我誰都沒看到」不可區分。
  可選強化：`visible()` 人人算得出 → 「看得到卻不報」本身是證據。列為選項。

## 12. 論文定位

HOCBF、Laplacian formation、ADMM-DMPC 三者各自引用來源，系統段寫「整合＋真分散部署」，
不對單一元件宣稱 novelty。主貢獻：
(a) **失效幾何**：偵測門檻與安全緩衝的耦合、安全預算由謊言位移而非速度決定、
    共識活性死鎖的分類；
(b) **分層防禦**：物理安全（保守錨定）不依賴偵測延遲，偵測層只決定協作與成員資格；
(c) 常數由系統自身物理導出的觀測式信任層，含明確的適用範圍與失效模式。
related work 寫作前需再掃一次 ADMM+HOCBF+formation 是否有同款組合的前作。
