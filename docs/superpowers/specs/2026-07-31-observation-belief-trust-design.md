# 觀測式信任層設計（Observation-sourced belief layer）

2026-07-31。取代現行 Gate 2 的單發殘差判決。

## 1. 問題

Gate 2 比對「同儕廣播的宣稱」與「同儕自己發的 odom」——**兩條都是被測者自陳**。
同時偽造兩條的攻擊者殘差恆 0，偵測永遠不觸發（Pasqualetti et al. 2013：內容型偵測器
看不見與所有自陳一致的攻擊）。已實測：`LIE=0.30` 全程合作、殘差穩定 0.424 < 門檻，
零 block、零 evict，真實車身間隙被吃到 0.038 m。

判決層另有兩個已實測的失效：LOGONLY 對照臂的 split-brain（兩隻倖存者判決差 9.5 s、
keep-out 圈差 4.5 m）、凍結攻擊者的過期 roster 仍在投票造成 coordinator 死鎖。

## 2. 目標與非目標

**目標**：讓物理安全不再依賴「宣稱誠實」。偵測地板必須低於傷害地板（D_MIN 1.3 −
接觸線 0.867 = **0.433 m**）。

**非目標**：真感知（本 spec 用零保真替身，見 §4）；Zikratov 的 reputation 陣列 S
（＝互相對第三方判斷是否一致而加分，防串謀用；N=3 無串謀情境可驗，留待 N≥5）；
改動 ADMM 迭代、HOCBF QP、Laplacian 編隊耦合、`admm_core` 數學、下層控制。

註：§3.3 的「證據來源加權」不在此排除之列——它是同一條更新規則的一部分（所有資訊按
對來源的信念加權），不是額外機制。被排除的是 S 那層跨代理一致性計分。

**設計紀律**（使用者要求，優先於一切便利）：泛用規則，不得有情境特化的 fallback。
每個離散行為都必須是同一條規則的讀數，不得是獨立分支。參數必須有物理意義與量測/推導程序。

## 3. 架構

信任層＝slot 級 admission control，掛在現行 `gate2()` 的位置。四步：

```
① 證據  我對同儕 j 的觀測 - j 廣播的宣稱 = 殘差 r_ij   （看不到 j → 無證據，不更新）
② 共享  觀測位置進 AgentState 隨 cycle-head 廣播 → 全隊同一份證據流
③ 信念  每狗對每同儕跑同一條似然更新 → b_j ∈ (0,1)，決定性 → 全隊同拍收斂
④ 讀數  同一個 b 出三個行為：admission / keep-out 裕度 / 成員資格
```

信念取端點 {1,0} 時精確退化為現行系統（分階段部署用）。

### 3.1 證據（步驟 ①）

- **觀測來源**：`peer_truth_`（已存在的 map）。模擬期由 Gazebo plugin 的
  `/robotN/hardware/odom` 餵入——它由模型世界位姿發布，不經 robot j 的估測器。
- **威脅模型（必要條件）**：觀測必須是**觀測者本地**的。ROS2 topic 無發布者認證，
  被入侵的 robot j **可以**往 `/robotJ/hardware/odom` 灌假資料，那樣整個前提就沒了。
  故：訂閱端 remap 進觀測者命名空間並驗發布者身分（模擬期用約定補上），
  真機天然成立（感測器是本機硬體，同儕寫不進來）。此假設寫入論文的威脅模型段。
- **可見性**：純函式 `admm::visible(p_i, p_j, obstacles, range, fov)`，線段-圓遮擋測試，
  帶單元測試。不可見 → **不產生證據**（不是產生反向證據）。
- **時間對齊**：宣稱是同儕 cycle head（20 Hz）的狀態，觀測非同步進來。0.55 m/s 下
  100 ms 偏差＝5.5 cm，相對 0.30 門檻是白送的空間，且會被誤寫進 σ。故觀測必須內插到
  宣稱的 `cycle_id` 時戳再相減（訊息已有 `cycle_id`、`tx_wall`）。現行 gate2 同病，一併修。
- **噪聲**：加 N(0, σ²)，且必須是 `hash(cycle_id, 觀測者, 被觀測者)` 的**決定性函數**，
  不可用循序抽樣（抽樣次數隨當拍可見數變動 → run 間發散，違反本專案 determinism 紀律）。
- **識別關聯（真感知的硬需求，模擬期不觸發）**：感測器說的是「那裡有一個物體」，
  不是「那是 robot 2」。**絕不可用「離宣稱最近」做關聯**——那會讓攻擊者的謊言牽著關聯走，
  殘差被構造性地壓到 0，偵測器自我作廢。必須用**時間軌跡連續性**關聯，身分只在信任時播種一次。

### 3.2 訊息欄位（步驟 ②）

`AgentState.msg` 追加兩欄（加欄位，非改協定；前例 `members[]`）：

```
int32[]   ev_peer     # 這一拍我有觀測到的同儕 id
float64[] ev_pos      # 對應的觀測位置 (x,y)，長度 = 2 * len(ev_peer)
```

**廣播觀測位置而非純量殘差**：殘差不可否證，位置則受幾何約束，接收者能在**自己看不到目標的
情況下**查核三件事——(a) 該位置是否在報告者感測範圍內；(b) 報告者到該位置的視線是否被柱子擋住
（`visible()` 人人算得出，場地已知）；(c) 是否與其他觀測者/自己稍後的第一手觀測吻合。
成本差 1 個 float，資訊嚴格更多。查核不過 → 該筆證據作廢（並構成對報告者的負面證據）。

空陣列＝我這拍誰都沒看到，語意上與舊版發送者相同（不影響 loopback 測試與舊 peer）。
一筆證據＝三元組 (觀測者＝訊息的 `robot_id`、被觀測者＝`ev_peer[k]`、觀測位置)，
時戳沿用 `cycle_id`。長度不符或非有限值 → 整包丟棄（同現行 Gate 1 語意）。

**每隻狗都是報告內容的直接查核者**：報告者也在報「我看到的你」，而你知道自己在哪——
誣陷者必須同時對所有其他人維持精準，任何一處偏掉當場被抓。這不是新機制，是同一條規則的結果。

### 3.3 信念更新（步驟 ③）

對每個同儕 j 維護對數勝算 L_j（log-odds），初值 0（無先驗）。每 slot：

```
L_j ← λ · L_j + Σ_i w_i · ℓ(r_ij)          # 無證據的 i 不進總和
b_j = 1 / (1 + e^{−L_j})
```

- `ℓ(r)` = 序貫似然比（SPRT 一族）：誠實假設 r ~ N(0, σ²) vs 說謊假設 r ≥ d_min_lie，
  取對數比並上下截斷（截斷防單筆離群值主宰，等價於 Zikratov ±1 量化的連續版）。
- `w_i` = **對證據來源 i 的信念 b_i**（上一拍值）。自陳與轉述一視同仁 →
  抹黑防禦是這條規則的結果，不是補丁。
- **轉述證據的權重上界＝對報告者的對數勝算**（似然本身條件在「報告者誠實」之上，
  非外加上限），且 b < 1 恆成立 → 單一指控者推不到驅逐門檻。
- **同來源對同目標的重複報告會飽和、不累加**（重複不是獨立證據；否則喊最大聲的贏）。
  推進需要第二個獨立目擊者，或幾何改變（遮擋是暫態的，第一手證據到場即定案）。
- `λ` = 遺忘因子（指數衰減）→ 過期證據自然失效，stale-vote 死鎖消失，無需過期規則。

### 3.4 行為映射（步驟 ④）

| 行為 | 映射 |
|---|---|
| admission | b 低於門檻 → 該同儕的宣稱不被 commit（走現行 `block_peer` 路徑），ADMM 更新式一字不改。連續權重進成本函數屬 CBF/QP 數學改動，依專案規則須先與使用者推導，本 spec 不做 |
| keep-out | 半徑＝f(b)，且 **f 在 b ≥ b_evict 區間必須是平的且等於現行 pairwise 約束**；只有跌破驅逐門檻後才連續長成屍體圈（b→0 即現行 `corpse_keepout`） |
| 成員資格 | b 跌破 b_evict → 走**現行** `members[]` 多數決驅逐路徑；回升過 b_rejoin → rejoin（雙門檻遲滯，防抖動） |

**keep-out 那條「平段」是硬需求，不是妥協**：b 初值 0.5，若半徑在信任區間就隨 b 膨脹，
三狗以 1.40 隊形 spawn 的**當下就違反約束**——即已記錄的「硬約束遇已違反狀態＝永久自鎖」。
連續性保留在不信任側；誠實艦隊的行為因此與現行**完全一致**（G3/G4 結果不受影響）。

沒有 OK/SUSPECT/EVICTED 狀態機——離散狀態只是 b 的讀數。
新成員/rejoin 無特製觀察期：零證據 → L=0 → b=0.5，隨證據爬升（論文 F(l) 的正規版）。

**分層**：CBF 物理安全層維持獨立於信任層（分層防禦，非 fallback）。

## 4. 保真度階梯與誤差預算（必須寫進論文的限制段）

模擬的觀測通道是**零保真替身**：世界座標 ground truth + 噪聲 + range/FOV/遮擋。
量的是「殘差路徑與判決端到端行為」，**不是**感測可行性。真光達的鏈是：

```
點雲(lidar frame) → base_link(URDF 外參，標定誤差) → odom(估測器：姿態 + 漂移)
                  → 共同世界座標(各狗各自的 registration ← 真機三大阻礙之首)
```

模擬完全沒有、真機一定有的四項誤差（`obs_range` 4 m 為基準）：

| 來源 | 量級 | 為何致命 |
|---|---|---|
| 姿態槓桿臂 | 1° → 4 m 處 **0.070 m**；3° → 0.21 m | trot 時機身俯仰數度；外參標定 1–2° 常見。門檻只有 0.30 |
| 狗間里程漂移 | 路徑的 1–5%，18 m 場地 → **0.2–1.0 m** | **隨任務時間成長**，終將超過任何 < 0.433 的門檻 → 長跑後誤殺誠實狗（＝安全機制歸零） |
| 表面 vs 原點偏差 | 最大約 **0.4 m**（機身半長） | 感測看到的是表面點雲，宣稱是 base 原點；偏差隨視角變動 → 像「時有時無的謊言」。是**系統偏差不是噪聲** |
| 掃描去畸變/時間同步 | 0.55 m/s × 掃描週期 ≈ 5 cm | 疊在上面三項之上 |

**設計結論**：真機版證據應改用**相對量**（距離為主，方位次之），可消掉座標系旋轉不匹配
並大幅削弱姿態槓桿臂；但**無法消掉兩狗世界座標 registration 的平移不匹配**——那需要
相對定位骨幹（互相觀測即可構成，是自然的下一步）。故論文宣稱必須限定範圍：
**模擬量到的 σ 是下界（floor），不是真機值**；真機部署需要觀測模型（外參、姿態、去畸變、
表面-原點偏差）與漂移感知門檻，否則誤判率由里程漂移決定、與攻擊者行為無關。

## 5. 參數與推導程序

| 參數 | 來源 |
|---|---|
| σ（觀測噪聲） | 量測：乾淨飛行校準 run 取殘差分布（repo 已有此程序，現行 log 無條件印殘差）。**模擬值是 floor，見 §4** |
| λ（遺忘率） | 推導：由「攻陷後行為改變的時間尺度」定，同現行 5-slot danger window 推法 |
| (α, β)（誤殺率/漏檢率） | **需求**，非旋鈕：給定目標錯誤率 → SPRT 標準式導出 b_evict、b_rejoin |
| d_min_lie（待偵測謊言下限） | 由 0.433 安全緩衝導出，且必須 **< 0.433**（偵測地板低於傷害地板）；現行 gate 0.30 是其上界的既有實例 |

零情境旋鈕：不得為追擊/引誘/潛伏各設一組。

## 6. 實驗矩陣（3 狗，plum arena）

三臂天梯，同一攻擊者、同腳本：

| 臂 | 設定 |
|---|---|
| A0 無防禦 | 偵測關（現有 `LIE_LOGONLY`） |
| A1 自陳 gate | 現行 Gate 2（`obs_gate2=0`） |
| A2 觀測信任層 | 本 spec（`obs_gate2=1`＋信念層） |

攻擊者：**雙通道偽造**（宣稱與 odom 同時造假，即 `ODOM_FAKE`＝`LIE`）——A1 結構上盲、A2 應可偵測。
各臂 n ≥ 3。

**量測**（全部已有工具）：`phys_gap_logger.py` 真實車身間隙（**唯一的接觸判準**）、
`dist.csv` 逐列掃（非 walk_until 稀疏輪詢）、time-to-evict、殘差/信念軌跡、任務完成、
`achieved_rounds`、WBC deactivation。

**驗收**：

1. A2 偵測到 A1 偵測不到的雙通道偽造攻擊者；報出 time-to-evict（**會比現行 0.405 s 慢**，
   累積證據的代價要誠實報，不得隱藏）。
2. NO_KILL soak 零誤殺（噪聲＋不可見情境下）。
3. **遮擋語意**：攻擊者躲柱後 → 無證據、信念凍住不誤殺；現身 → 證據恢復、被偵測。
   （這是自陳架構連表達都表達不了的新宣稱。）
4. 重跑 stale-vote 死鎖場景：遺忘因子應自然消解，無需特例。
5. **誣陷臂**：攻擊者不動自己的位置、改為廣播對誠實同儕的假觀測 → 誠實狗**不得**被驅逐
   （轉述證據單獨不驅逐），且誣陷者本身因對第三方報告不實而被抓。
6. 回歸：44 oracle + 5 ctest 全過；`b≡1` 時與現行系統行為一致（含 G3/G4 幾何）。

## 7. 已知盲區（誠實條款，寫進論文）

- **對稱 1v1**：j 說謊、i 指控 j、j 反咬 i、第三方 k 恰好誰都看不到 → 證據對稱，
  似然到不了門檻 → **不開除**（i、j 互相 keep-out，安全不賠、活性降級）。
  理論上不可判定（BFT 需 3f+1），非實作缺陷。N 增大時目擊者增多，盲區自動縮小，零改碼。
- **轉述證據單獨永不驅逐**：需第一手佐證或幾何改變。最壞退化是活性，不是誤殺誠實狗
  ——誤殺＝看起來像死了＝安全機制歸零，是比慢一拍嚴重得多的失敗方向。
- **沉默規避**：攻擊者可以永遠不報告觀測，與「我誰都沒看到」不可區分（因為「無證據＝不更新」
  是刻意的）。可選強化：`visible()` 人人算得出 → 「看得到卻不報」本身是證據。
  模擬期可見性確定故免費；真感知下必須放寬。**列為選項，非必做**。

## 8. 影響面

改：`admm_agent_node.cpp`（gate2 → 信念層）、`AgentState.msg`（+2 欄）、
`fleet_config.hpp/cpp`（`visible()`、信念更新純函式、keep-out 隨 b 縮放）、
`d_run.sh`（接 OBS_GATE2/ODOM_FAKE 與三臂矩陣、誣陷臂）、對應單元測試。

**驅逐只能有一條路徑**：信念跌破門檻 → 現行 `block_peer` → 現行沉默驅逐。
不得新開第二條判決路（那就是被禁止的特例）。

不改：ADMM 迭代與 barrier、HOCBF QP、Laplacian 耦合、`admm_core` 數學、
coordinator 指派、下層 OCS2/WBC。G1 bit-identical parity 必須維持。

## 9. 論文定位（附帶結論，非本 spec 交付物）

HOCBF、Laplacian formation、ADMM-DMPC 三者**各自引用來源**，系統段誠實寫成
「整合＋真分散部署」，不對單一元件宣稱 novelty。主貢獻是：
(a) 失效幾何三發現（偵測門檻 > 安全緩衝、攻擊者速度優勢、共識活性死鎖）；
(b) 本信任層——常數由系統自身物理導出，使物理安全不依賴宣稱誠實。
related work 寫作前需再掃一次 ADMM+HOCBF+formation 是否有同款組合的前作。
